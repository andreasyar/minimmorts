## Локальные спрайты

51 PNG (49 953 байта) скопированы из
`minimmorts-legacy/archive-findings-2026-10-25/sprites-v3/`
в `client/src/sprites/` с сохранением имён и содержимого.
Восемь совпадающих пар статических изображений и кадров `_walk_0`
оставлены под обоими именами: их запрашивает клиент.

По решению владельца проекта спрайты хранятся только локально:
авторские права на них проекту не принадлежат. Каталог явно исключён
из Git через корневой `.gitignore`.
После обычного клонирования репозитория этих файлов не будет.
Контрольные суммы есть в [sprites.tsv](legacy-audit-2026-10-25/sprites.tsv).

Оригинальный `peasant_follow.png` в архивах не найден. Взамен создан новый
PNG 72×72 с прозрачным фоном и жёлтыми уголками вокруг фигуры юнита.
Это мигающая отметка цели следования, которую рисует `FollowBlinkAnimation`.
Изображение создано на Python/Pillow, без использования пикселей исторических
спрайтов; оно не является восстановленным оригиналом. Скрипт
`python3 client/tools/create-follow-sprite.py` повторно создаёт файл в
`client/src/sprites/`; готовый PNG хранится локально вместе с остальными спрайтами.

Библиотеки и остальные архивные данные не переносились:
сборка будет переделываться отдельно.

## Текущая структура клиента

Flash-клиент удалён из рабочего дерева; его исходники доступны в Git-истории.
Бывший `client/HTML5/src/` перенесён в `client/src/`,
а `client/HTML5/bot/` — в `client/bot/`.
Основная страница клиента — `client/src/client.html`, бота —
`client/bot/src/client.html`. Исторические отчёты и wiki сохраняют прежние пути
как сведения о состоянии проекта на момент их написания.
