## Границы вывода

Результат относится к данным внутри указанного `minimmorts-legacy`.
Внешние большие архивы резервных копий и другие каталоги не исследовались.
Сторонние библиотеки в `lib`, генерируемые `build`/`dist`, документация библиотек
и SVN property-base не учитываются как самостоятельный авторский игровой код.
Бинарные `.class`/JAR не декомпилировались; игра не запускалась.
Исторические свойства SVN и исходная точность времён продолжают храниться в legacy;
полное побайтовое воспроизведение SVN-репозитория этим аудитом не заявляется.

В legacy отдельно есть восстановленные спрайты и диагностические логи.
Они могут быть полезны для восстановления запуска и изучения поведения игры,
но не являются найденным потерянным исходным кодом. Перенос ресурсов в проект
в этот аудит не входит.

## Воспроизведение

Из корня репозитория:

```sh
python3 doc/legacy-audit-2026-11-03/audit.py
```

Нужны только Python 3 и Git. Скрипт читает legacy и Git, записывает
`evidence.json` рядом с собой; архивы не распаковывает и исходники не меняет.
В JSON сохранены refs, контрольная сумма исходного ZIP, сопоставления каждого
проверенного экземпляра с Git blob, различия двух уникальных файлов,
результаты проверки SVN-журнала, рабочих копий и пяти деревьев ZIP.
